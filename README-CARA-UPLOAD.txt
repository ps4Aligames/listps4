CARA UPLOAD KE GITHUB - ps4aligames/DAFTARgameps4

1. Buka https://github.com/ps4aligames/DAFTARgameps4
2. Upload index.html dan .nojekyll ke root (tombol Add file > Upload files)
3. Untuk workflow:
   - Jika di Settings > Pages > Source = GitHub Actions:
     Klik Configure di Static HTML, commit, selesai
   - Atau manual: buat folder .github/workflows/ lalu upload static.yml ke sana
4. Tunggu 1-2 menit di tab Actions sampai hijau
5. Buka https://ps4aligames.github.io/DAFTARgameps4/

File static.yml sudah ada di ZIP ini, tinggal upload ke .github/workflows/
